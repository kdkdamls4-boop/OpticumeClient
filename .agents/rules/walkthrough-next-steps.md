# Правило оформления Walkthrough

- В конце каждого артефакта `walkthrough.md` **всегда** добавляй раздел **«Следующие рекомендуемые действия»** (`## Следующие рекомендуемые действия`), содержащий чёткий нумерованный список практических шагов для пользователя (что протестировать, какие команды запустить и какие улучшения можно сделать дальше).
